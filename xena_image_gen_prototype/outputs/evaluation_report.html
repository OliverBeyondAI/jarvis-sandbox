Methodology

Evaluation mode: Automated metrics (resolution, file size, color proximity)

Scoring: Each image is scored 1–5 on four criteria: prompt adherence, visual quality, text rendering accuracy, and brand consistency. A score of 0 indicates the image was not found (generation not run or failed).

Models: OpenAI gpt-image-1 and Google imagen-3.0-generate-002.

Data source: All scores in this report are derived from the evaluation pipeline (no images were generated yet). Run the generation scripts with valid API keys to populate scores.

How to Run

1. Set API keys in .env:

OPENAI_API_KEY=sk-...
GOOGLE_GENAI_API_KEY=...

2. Generate images:

python generate_openai.py
python generate_gemini.py

3. Evaluate and produce reports:

python evaluate.py          # automated metrics
python evaluate.py --llm    # LLM-assisted (requires ANTHROPIC_API_KEY)
